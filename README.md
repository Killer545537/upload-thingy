# UploadThingy 📦🚀

**UploadThingy** is a simple, performant file uploader built with modern web tooling.  
It focuses on clean architecture, strong typing, and a minimal but extensible upload flow.

---

## ✨ Tech Stack

### 🧱 Core
- **Next.js 16** — App Router, server-first architecture
- **React 19** — Concurrent-ready UI
- **TypeScript** — End-to-end type safety

### 🔐 Authentication
- **Better Auth** — Simple, flexible authentication

### 📤 File Uploads
- **UploadThing** — Secure, direct-to-storage uploads with excellent DX

### 🗄️ Database & ORM
- **Neon Postgres** — Serverless PostgreSQL
- **Drizzle ORM** — Type-safe SQL and schema management

### 🎨 UI & Styling
- **Tailwind CSS**
- **ShadCN UI**
- **Lucide React**

### ✅ Validation
- **Zod** — Runtime and schema validation

### ✉️ Email
- **Resend**
- **React Email**

---

## 🎯 Goals

- 📁 Simple, secure file uploads  
- 🔒 Auth-gated access  
- 🧩 Minimal backend complexity  
- 🧠 Strong typing across the stack  
- 🔧 Easy to extend (quotas, file management, sharing, etc.)
